# Тестирование проекта Codebattle (codebattle.hexlet.io)

## 📌 О тестируемом проекте
**Codebattle** — это открытая веб-платформа с открытым исходным кодом (разработанная компанией Hexlet) для проведения многопользовательских соревнований по программированию в режиме реального времени. 

**Ключевые особенности продукта:**
*   **Real-time режим:** Мгновенная синхронизация данных. Игроки видят, как пишет код их соперник, в прямом эфире.
*   **Поддержка языков:** Возможность программировать на различных языках (Python, JavaScript, Ruby, Go, C++ и др.).
*   **Режимы игр:** Игра со случайным соперником, вызов конкретного игрока, игра с ботом и тренировочный режим.
*   **Зрители и общение:** Возможность наблюдать за чужими играми в реальном времени, а также общаться в общем и игровом чатах.
*   **Рейтинг:** Глобальная система рейтинга (ELO) и статистика побед.

Учебный проект Хекслета: https://ru.hexlet.io/programs/qa-engineer
